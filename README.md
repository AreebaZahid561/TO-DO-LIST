Modern React To-Do Application

An attractive, highly responsive, and feature-rich To-Do application built with React and Vite. It combines a stunning modern UI — featuring glassmorphism, gradient accents, and subtle animations — with practical task management capabilities.

✨ Features

 Core Tracking (Phase 1)

* Add new tasks effortlessly
* Mark tasks as completed with strike-through and fade effects
* Delete unwanted tasks permanently

Organization & Theming (Phase 2)

🔥 Priority Labeling

Assign High or Low priorities to your tasks.

📅 Due Dates

Integrated browser-native calendar date picker.

⚠️ Overdue Detection

Tasks that pass their due date automatically emit a pulsing red aura effect to grab your attention.

🌙 Dark & Light Mode

Seamlessly switch between themes using a smooth animated toggle.


Advanced Controls (Phase 3)

↕️ Drag & Drop Reordering

Freely reorder tasks using intuitive drag-and-drop functionality powered by `@hello-pangea/dnd`.

💾 Local Storage Persistence

Tasks and theme preferences are automatically saved in the browser and restored after refresh.

🔍 Smart Filtering

Filter tasks by:

* All
* Pending
* Completed

🖼️ UI Highlights

* Modern glassmorphism design
* Gradient backgrounds and glowing accents
* Smooth transitions and animations
* Fully responsive layout for desktop and mobile
* Accessible drag-and-drop interactions

🚀 Technologies Used

* **React** (via Vite) — Fast component-based UI development
* **Vite** — Lightning-fast build tool and development server
* **Vanilla CSS** — CSS Variables, Flexbox, Grid, and Keyframe Animations
* **@hello-pangea/dnd** — Accessible drag-and-drop support
* **date-fns** — Date formatting and overdue calculations
* **lucide-react** — Beautiful modern icon set

📂 Project Setup

1️⃣ Clone the Repository

```bash
git clone <https://github.com/AreebaZahid561/TO-DO-LIST>
```


 2️⃣ Navigate into the Project Folder

```bash
cd to-do-app
```


 3️⃣ Install Dependencies

```bash
npm install
```

4️⃣ Start the Development Server

```bash
npm run dev
```

 5️⃣ Open in Browser

Visit:

```txt
http://localhost:5173/
```


📦 Build for Production

```bash
npm run build
```
